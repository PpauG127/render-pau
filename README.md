# shorts-render
Shorts de ciencia visual (1080x1920) generados con código.

- Render en la nube: pestaña **Actions → render → Run workflow** (o push a `videos/`). Los mp4 aparecen en **Releases**.
- Render local: `tools/setup.sh && tools/render_local.sh motor_electrico`
- Revisión rápida: `python videos/<slug>.py sheet hoja.png`
